# Shadow Nexo 1.15.0

Version de escritorio de Nexo AI con la interfaz nueva (Dashboard, orbe de voz, fondos animados, Buscar chats).

Esta carpeta es el contenido de `app.asar` de la app instalada: la interfaz (`dist/`) esta compilada y minificada; el codigo principal esta en `src/`. El fuente original de Nexo AI esta en la raiz del repo (rama `main`).

Para ejecutar: `npm install` y luego `npx electron .`
